### 需求不是权限

问题图保留六个建议字段：范围 scope、时效 freshness、本地资料可能性 local_possible、是否建议联网 needs_web、原因 reason、来源要求 source_requirements。DeepSeek 可提出建议，但不得指定任意域名、URL 或新的工具。

“预测峰值是多少？House Mill 最近有什么活动？”拆成两项：峰值必须走项目工具，活动可建议读取机构官网。程序从原文识别近期、数值和来源限定；模型不能删去“不要联网”来获取许可。寒暄、概念解释不必联网；静态背景先查本地，有缺口可通过 local_missing 标明。数值、内部规则、毕业论文中的事实、实时警报状态、现场安全判断和账号操作不走外部查证。

网页主流程尚未提供联网开关，也不会因为 DeepSeek needs_web=true 自动抓网页。独立 CLI 需明确 --allow-web。运行细节的 network_disabled 是预期，不表示项目问答失效。

### 两个工具分离

search_public_web：可选 Brave Web Search 适配器；只发送获准原文问题项片段，加来源域名限制；程序再次过滤结果 URL，返回最多 3 个候选。未配置 BRAVE_SEARCH_API_KEY 或仍为占位符时，返回 search_not_configured，零 HTTP 调用。你没有搜索提供商，因此未注册／购买服务，未执行真实搜索。搜索摘要不作为事实。

fetch_public_page：只读公开 HTML，返回标题、文本段落、读取 UTC 和原始响应哈希；不保存网页缓存，不加入知识目录，也不交给 DeepSeek 生成项目答案。HTTP Last-Modified 仅保留为未核验头信息，不冒充发表时间；published_at 暂为 null。

网页条目状态均为 unverified。文本提取删除脚本、表单、部分隐藏节点等，但不会识别全部 CSS 隐藏或提示注入。可见“忽略规则”文本依然可能存在于候选正文中；本阶段没有任何解释器执行它。

### 网络边界

精确主机白名单按主题划分，拒绝后缀冒充域名、认证信息 URL、非 HTTPS／非 443、IP URL、任意 URL。逐一检查 DNS 全部 A/AAAA 结果，拒绝私网、回环、链路本地、保留、多播和特殊隧道地址；连接固定到通过检查的地址，不二次解析。TLS SNI 和证书仍按原域名验证。环境代理不被采用，没有 Cookie 或网页授权头。搜索 key 仅能发往固定 Brave 接口。

全部重定向拒绝，无自动重试。网络预算最多 4 请求／20 秒，DNS 最多 6 秒、连接／读取最多 8 秒且受剩余预算限制；最多 1 MB，仅接受相应 JSON／HTML，拒绝压缩与 PDF 等文件。预算为协作式，不是覆盖所有操作系统调用的进程级硬截止。此阶段是独立工具预算，尚未与多步调查的总预算融合。

## 你如何测试

在项目目录运行以下命令；均沿用现有环境。前四条不联网、不消耗 API：

```powershell
cd C:\UCL\CASA0016\FloodPred-Agent
.\.venv-d4\Scripts\python.exe -X utf8 -m app.web_cli policy "预测峰值是多少？House Mill 最近有什么活动？" --allow-web
.\.venv-d4\Scripts\python.exe -X utf8 -m app.web_cli policy "不要联网，House Mill 最近有什么活动？" --allow-web
.\.venv-d4\Scripts\python.exe -X utf8 -m app.web_cli demo --allow-web
.\.venv-d4\Scripts\python.exe -X utf8 -m unittest tests.test_web -v
# 以下需要网络权限，但不需要搜索服务：
.\.venv-d4\Scripts\python.exe -X utf8 -m app.web_cli fetch "英国官方洪水公开资料" --allow-web --url https://www.gov.uk/prepare-for-flooding
# 尚未配置时应说明 search_not_configured：
.\.venv-d4\Scripts\python.exe -X utf8 -m app.web_cli search "House Mill 最近有什么活动？" --allow-web
```

预期：混合问一项 project_source_only、一项 eligible；禁止联网样例为 user_forbidden；模拟资料明确不是实际活动；真实抓取只给未核验预览。失败退出码为 2。将来采用 Brave 后在本机配置 BRAVE_SEARCH_API_KEY，别把 key 发到聊天或 GitHub。

## 技术栈与后续

Python 标准库实现策略、DNS、固定 IP HTTPS/TLS、HTML 文本提取、JSON、SHA-256 和测试；DeepSeek 仍用于可选结构化规划；保留现有 Streamlit、Pydantic、NumPy、SQLite、BM25/LSA/RRF。不新增 LangGraph、LangChain、Python 环境或依赖。

下一步先做独立网页快照与来源定位（第 3 步），再做外部证据支持检查（第 4 步），之后才加入现有有限调查循环和用户开关（第 5–6 步）。尚缺并发出网控制、独立网络出口防护、robots／站点访问策略与动态正文的语义核验；不要把此版部署为任意网址爬虫或实时现场决策工具。
