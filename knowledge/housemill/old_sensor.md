# Earlier House Mill monitoring installation (curated paraphrase)
The djdunc/housemill README documents an earlier monitoring installation: a MaxBotix MB7389 sonar connected to an Arduino and Raspberry Pi, plus a Pi NOIR camera with infrared illumination. Equipment was placed within the mill above an opening towards the channel. The Pi sent readings via Wi-Fi/GSM to an MQTT broker; the project used InfluxDB and Grafana for storage and display. The README describes roughly ten-minute sonar reporting and fifteen-minute river/tide reference data. This is historical project documentation, not proof that the installation is operating today.
Source: https://github.com/djdunc/housemill ; README, checked 2026-09-30. The README describes both 10 and 11 raw samples per interval in different places, so no exact per-interval count is asserted here.
